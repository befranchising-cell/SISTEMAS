# Trinità · Landing Page de Franquias

Landing page de venda de franquias da Trinità Imobiliária, baseada na Apresentação de Franquias v5 (out./2026).

- `index.html`: página completa (HTML + CSS), fonte para a versão publicada no Lovable.
- `img/`: fotos da fachada da unidade própria e dos sócios (João Cataldo e Danielle Vieira), extraídas da apresentação.
- As fotos de imóveis vêm do site trinita.rio.br (media.imobzi.com).
