# Zoom Loca · Landing Page de Franquias

Landing page de venda de franquias da Zoom Loca, baseada nas Apresentações Comerciais v4 (Loja Full) e v1 (Operador), set./2026.

- `index.html`: página completa (HTML + CSS + JS), fonte para a versão publicada no Lovable. Seletor de formato (Operador / Loja Full) e formulário que abre o WhatsApp (15) 99650-5500 com os dados do lead.
- `img/`: logos, moto da capa, fachadas, fundador e Yamaha Factor, extraídos do PDF original.
- Na página, as imagens apontam para a pasta do Drive "LP FRANQUIAS - IMAGENS" (dentro de 07 - EXPANSÃO / APRESENTAÇÃO COMERCIAL da Zoom), compartilhada por link.
