# Formosa Flores · Entrega de Materiais e Manuais

Página estática com todos os materiais da consultoria Negócio Classe A para a Floricultura Formosa (abr a ago/2026), organizados em 6 etapas e os registros editáveis.

## Acesso com senha

O conteúdo está criptografado (AES-256-GCM, chave derivada da senha com PBKDF2). Sem a senha, os arquivos do repositório não abrem. A senha é passada ao cliente pela consultoria. Ela não fica salva aqui.

## Como abrir

Publique a pasta num servidor estático (GitHub Pages, por exemplo) e abra `index.html`. Abrir o arquivo direto do computador não funciona, porque o navegador bloqueia a leitura dos arquivos `.enc`.
